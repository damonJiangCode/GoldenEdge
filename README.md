# GoldenEdge

Strategy research workspace.

XAU strategies are organized by strategy and version:

```text
xau/
├── vb/v1/
├── mr/v1/
├── tp/v1/
├── marketdata/
├── changelog.md
└── readme.md
```

See [`xau/readme.md`](xau/readme.md) for the current XAU structure, commands, and
unified trade schema.

Raw XAU market data:

```text
xau/marketdata/
```
